# Брендові reels для @golikov.psychologyst

Пресет для цитатних вертикальних відео (Instagram Reels) у стилі шаблону
@sharonacheryll, але у фірмових кольорах і українською.
Якщо користувач просить «зроби таке саме відео» / «ще один рілс» — бери звідси.

Текст на світлому фоні — `ink`. Текст на темному фоні — `goldLite` + тінь
`0 2px 10px rgba(0,0,0,.50), 0 0 26px rgba(0,0,0,.28)`.
Логотип Instagram і нік — завжди `goldLite` (НЕ фірмовий градієнт Instagram).

## Шрифти

- Серифний (сцена 1, ВЕРХНІЙ РЕГІСТР): **Playfair Display Bold (700)**
- Гротеск (сцена 2): **Montserrat Bold (700)**
- Обидва з кирилицею, ставити локально з npm: `@fontsource/playfair-display`, `@fontsource/montserrat`
  (woff2-сабсети `cyrillic` + `latin`; Google Fonts CSS доступний, gstatic — ні).

## Геометрія кадру

- Полотно **720×1280**, фон чорний.
- Смуга контенту **720×404**, по центру вертикалі — `top: 438px`.
- Вотермарка вгорі праворуч: `right: 52px; top: 296px`, іконка 34px, нік 17px/700, letter-spacing .9px, gap 7px.
- Фінал: іконка 94px, нік 23px/700, letter-spacing 1.2px, відступ 32px; блок `top: 129px` всередині смуги.

## Ритм (головне — не міняти)

- **Сітка склейок 0.30 с**, жорсткі різи, БЕЗ жодних плавних переходів.
- Слова з'являються по одному, теж кожні 0.30 с, зліва направо.
- Фон строго чергується світлий/темний по цій самій сітці.
- Один такт «зависає» подвійно саме на стику сцени 1 → сцени 2.
- Фінал стартує з такту, з якого фон більше не чергується: затемнення + лого + нік.
- При 30 fps такт = рівно 9 кадрів (краще за 24 fps, де виходить 7.2).

## Два варіанти розкладки (обидва трапляються)

**Тип A — «по центру»** (реф. «JUST BECAUSE YOU LOVE THE SEA»):
сцена 1 сериф 50px/54px, ліворуч, `padding-left: 72px`;
сцена 2 гротеск 42px/52px, **по центру**; блок по центру вертикалі смуги.
Фони: папір ↔ фото ↔ дим (три штуки). Фінал — на папері.

**Тип B — «по лівому краю»** (реф. «WHAT DOESN'T KILL YOU»):
обидві сцени ліворуч, `padding-left: 78px`, прив'язка до ВЕРХУ смуги (перший рядок ~y=80);
сцена 1 сериф 54px/58.5px; сцена 2 гротеск 42px/43.5px (щільний інтерліньяж).
Фони: лише папір ↔ фото. Фінал — на **затемненому фото**, плюс один чорний кадр на стику.

## Фони

1. **Папір** — процедурний: колір `paper`, вертикальні волокна, легка віньєтка.
2. **Фото** — справжній знімок, градуйований у палітру (див. нижче), повільний зум 1.05→1.105.
3. **Дим** (лише тип A) — процедурний fBm-шум, рампа `ink → ink2 → ink3 → goldDeep → gold`.

### Градування фото (split-tone) — ключове

Не заливка кольором, а монотонне відображення яскравості, тому вся
фотографічна деталізація зберігається:

```
v = luma(r,g,b)                       // Rec.709
v = (v - 0.5) * 1.16 + 0.54           // S-крива + підйом
warm = clamp((r - b)/255 * 1.7, 0, 1) // тепле піднімається по рампі в золото
v = clamp(v + warm * 0.34, 0, 1)
колір = ramp(v, [0 ink*0.4, .20 ink*0.7, .40 ink, .58 ink2,
                 .72 mix(ink3,goldDeep,.3), .84 goldDeep, .93 gold, 1 goldLite])
```

Без доданка `warm` захід сонця (середня яскравість, але теплий) сідає в
зелений і небо читається як ще одна вода.

Далі: скрим ліворуч `rgba(ink*0.4, .42)` під текст + віньєтка 0.42.
Фото рендерити в канвас **2×** (1440×808), CSS стискає до 720×404 — зум лишається різким.

## Звідки брати фото (мережа сесії вузька)

Проксі пускає лише `raw.githubusercontent.com`, `github.com`, `registry.npmjs.org`,
`files.pythonhosted.org`, `fonts.googleapis.com`. Unsplash/Pexels/Wikimedia — заблоковані.

Робоче джерело: **`elementary/wallpapers`**, гілка `master`, тека `backgrounds/`.
Ліцензії — у `debian/copyright` на гілці `deb-packaging`: фото Unsplash до 08.06.2017 → **CC0**,
пізніші → ліцензія Unsplash, окремі — Pexels. Усі дозволяють комерційне використання без атрибуції.

Перевірені файли (назви з пробілами → urlencode):

### Як обирати кадр під сенс

1. Спершу сформулювати, про **що саме** цитата: не «море», а «повертається щоразу».
2. Кроп робити так, щоб під текстом (ліва половина, y 0.19–0.72 смуги) була **темна й спокійна**
   зона. Світла фактура під нижніми рядками — головна причина, чому гарний кадр не йде.
3. Перевіряти обов'язково на **довгому** тексті сцени 2, а не на заголовку: перевіряти
   треба найгірший випадок. Рендерити кандидатів через `?photo=assets/try_X.jpg`.
4. Перебирати по 3–4 варіанти одразу контактним аркушем — швидше, ніж міркувати.

Поряд із відео завжди класти `CREDITS.txt` із посиланням і ліцензією.

## Звук

За замовчуванням — доріжка з референсного відео користувача (щоб склейки лягли на біт),
`afade=t=out` за 0.22 с до кінця аудіо. Обов'язково попереджати: для публікації
краще замінити на трек із бібліотеки Instagram. Сітка 0.30 с = 100 BPM, лягає майже на будь-що.

## Видача

Рендер: Chromium (Playwright) покадрово → PNG → ffmpeg.
`libx264 -preset slow -crf 19 -pix_fmt yuv420p -profile:v high -level 4.0 -movflags +faststart`,
аудіо `aac 160k`. Зерно 5.5% (`mix-blend-mode: overlay`) — переживає кодування без блочності.

Віддавати: три відео (по палітрі), лист порівняння палітр, обкладинки (кадр ~2.1 с).
